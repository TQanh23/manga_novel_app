# app

Expo (React Native) + Expo Router client, one TypeScript codebase for Android and web.

```bash
npm install
npx expo start        # press w for web, a for Android
npm run typecheck
npm run lint
```

Routes live in `src/app/`. Keep components, hooks and utilities outside that folder.
See `AGENTS.md` for Expo-specific rules and the root `CLAUDE.md` for project conventions.
